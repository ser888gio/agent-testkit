## Why 006 and 007 jumped the queue

The 2026-08-26 audit ranked 001–005 by leverage. The 2026-08-29 re-audit found
something that outranks all of them: **CI has never run.** Both workflows
trigger on `branches: [main]`, but the default branch is `develop` and every
recent PR (#79–#87) targets it. `gh run list` shows zero `CI` workflow runs.

The suite on `develop` is consequently red, and two of the four failures are
live product defects that existing tests already caught:

- `reports/md.py:_timeline_block` has no `return`, so `agentaudit report
  --format md` — the default report format — raises `TypeError` on any run with
  a failing multi-turn test.
- `agentaudit/config/treasury-http.yaml` lost its `{{ input }}` placeholder in
  commit `3b89e3e`, so the HTTP agent POSTs the literal string `"input"` for
  every test instead of the prompt.

Neither would have reached `develop` with a working gate. 006 closes the
defects, 007 closes the gate.

  console-script form, which **fails on Windows** (`uv trampoline failed to

  should substitute `python -m pytest`.

  BaseHTTPMiddleware` import alongside an `@app.middleware("http")` decorator
  that does not need it. Ruff `F401` will flag it; drop the import.
